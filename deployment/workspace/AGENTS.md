# Remote Vibecoding workspace

This directory contains two independent Git repositories and is not itself a
Git repository. Read the target component's AGENTS.md before changing it.
Telegram behavior belongs to telegram-vibecoding. Host execution, API, common
Compose operations and recovery belong to vibecoding-core.

Work personally without subagents. Preserve both repositories, native session
identities, captured input, private credentials and existing host services.
Run common commands from this workspace and component checks from their owners.
Do not add a third repository or move Docket as a side effect.
